1. Abstract

With the rapid expansion of digital streaming media platforms, entertainment distributors face fundamental challenges in catalog discovery, customer churn reduction, and acquisition planning. This mini-project presents an end-to-end analytical data mining architecture that unifies theatrical viewer preferences from the MovieLens 100k dataset (100,836 ratings across 9,742 movies) with commercial video-on-demand distribution patterns from the Netflix Titles catalog (8,807 streaming records). The system executes an automated, idempotent ETL pipeline loading raw records into a conformed Fact Constellation Data Warehouse in SQLite across 5,340 conformed dates with complete relational foreign key integrity.

Upon this multidimensional warehouse, five complementary data mining modules are executed: (1) Apriori market-basket mining discovering 935 high-lift co-viewing association rules (Lift up to 6.15x); (2) Multinomial Naive Bayes natural language processing classifying plot summaries into genres with 50.49% accuracy; (3) Balanced Random Forest predicting movie rating tiers with 63.01% accuracy without data leakage; (4) Regularized Lasso regression performing sparse feature selection (Test RMSE: 0.4683); and (5) Box-Jenkins ARIMA(3,1,3) time series modeling achieving a 22.47% forecast improvement over naive persistence. Finally, a weighted hybrid recommender engine evaluated offline via Leave-One-Out Hit-Rate@10 (0.0467) and served through an interactive Flask web application provides practical, explainable deployment.

2. Introduction

Modern media distribution relies extensively on data mining algorithms to extract actionable intelligence from vast, heterogeneous consumer interaction logs. Online streaming services generate continuous transaction feeds, descriptive metadata, and temporal catalog releases. Examining these multidimensional datasets manually is infeasible due to extreme sparsity and combinatorial complexity. Data mining bridges this analytical gap by uncovering latent associations between titles, classifying unstructured narrative synopses, projecting temporal catalog growth, and personalizing viewing queues.

By integrating traditional market-basket analysis (Apriori) with statistical time series forecasting (ARIMA), text mining (TF-IDF vectorization), and supervised ensemble learning (Random Forest), content providers can reliably predict audience reception, optimize procurement budgets, and deliver transparent, explainable recommendations to subscribers without black-box opacity.

3. Problem Statement

To ingest, cleanse, and structure heterogeneous movie rating logs and streaming catalog metadata into an analytical Fact Constellation warehouse, and to apply association rule mining, text classification, predictive regression, and ARIMA temporal modeling so that co-viewing affinities, rating tiers, and platform catalog trends can be reliably discovered, evaluated, and served through an explainable recommendation interface.

4. Aim and Objectives

Aim: To design, develop, and empirically evaluate an integrated Movie and OTT Recommendation and Trend Analysis system using multidimensional warehousing and core data mining algorithms.

  • Construct an idempotent ETL pipeline to assemble a SQLite Fact Constellation schema with conformed date dimensions and 0 orphan keys.
  • Formulate user viewing records into transactional baskets and apply Apriori to mine frequent itemsets and co-viewing rules.
  • Develop a text mining pipeline using NLTK Porter Stemming, TF-IDF vectorization, and Multinomial Naive Bayes to classify plot synopses.
  • Engineer leak-free metadata features and train Decision Tree and Random Forest classifiers to predict movie rating categories.
  • Train and benchmark Linear, Ridge, and Lasso regression models to estimate continuous movie ratings and analyze active L1 feature weights.
  • Conduct ADF stationarity tests and fit ARIMA models on monthly additions to forecast catalog expansion with 95% confidence intervals.
  • Synthesize Content-based, Item-Item Collaborative Filtering, and Apriori rules into an explainable Hybrid Recommender (evaluated via Hit-Rate@10).
  • Deploy an interactive Flask web application and Chart.js analytical dashboard for real-time inference.

5. Scope of the Project

The project encompasses end-to-end data processing, from raw CSV cleansing to analytical warehousing, model training, offline mathematical evaluation, and interactive dashboard deployment. All reported metrics reflect empirical test evaluations on fixed splits without data leakage. The project operates on benchmark historical catalogs (MovieLens 100k and Netflix Titles); it does not establish causal human behavior nor perform automated live video transcoding.

8. Methodology and Algorithm

The system follows a sequential 8-stage data mining lifecycle:

  • Step 1 – Ingestion & Discovery: Robust automated path discovery scanning nested directories, reading raw CSVs into DataFrames.
  • Step 2 – Fact Constellation ETL: Automated idempotent relational pipeline loading 11 normalized tables into SQLite with primary/foreign keys.
  • Step 3 – Basket Assembly & Apriori Mining: Formulated 599 users × 300 movies binary co-viewing matrix. Extracted frequent itemsets and association rules using mlxtend.
  • Step 4 – Text Mining & Naive Bayes: Plot synopsis cleaning, Porter stemming, TF-IDF vectorization (20,000 max features), and MultinomialNB tuning.
  • Step 5 – Rating Tier Classification: Engineered 22 leak-free features (19 genre flags, release year, log ratings, tag counts) and trained Random Forest.
  • Step 6 – Regularized Regression: Evaluated Linear, Ridge, and Lasso regression models with cross-validation to analyze L1 coefficient sparsity.
  • Step 7 – Time Series Differencing & ARIMA: Stationarity verification via ADF unit-root test (d=1), grid search over (p,1,q), and 12-month holdout evaluation.
  • Step 8 – Hybrid Recommender & Serving: Linear ensemble of Content-based, Item-CF, and Apriori rules served through a responsive Flask web app.

Key Measures and Mathematical Formulations

Measure / Algorithm Mathematical Formula / Objective Function Interpretation in Project Context
Support support(A → B) = P(A ∪ B) = Count(A ∪ B) / N Fraction of user viewing baskets containing both titles.
Confidence confidence(A → B) = P(A ∪ B) / P(A) Conditional probability that a user likes title B given they liked A.
Lift lift(A → B) = confidence(A → B) / support(B) Affinity strength: Lift > 1 indicates positive association above independence.
Naive Bayes P(c | d) ∝ P(c) ∏ P(w_i | c) Posterior genre probability given word tokens in plot synopsis.
Lasso (L1) min (1/2n)||y - Xβ||² + λΣ|β_j| L1-penalized regression driving uninformative genre weights to exactly 0.
ARIMA(p,d,q) φ(B)(1-B)&supd; y_t = θ(B)ε_t Autoregressive integrated moving average for monthly OTT additions.
Hybrid Score S_h = 0.40 S_content + 0.30 S_cf + 0.30 S_rule Dynamic linear combination with weight normalization for missing signals.

12. Limitations and Future Scope

Limitations: (1) The MovieLens 100k catalog spans 1996–2018 theatrical releases whereas Netflix additions span 2008–2021, reflecting divergent distribution channels. (2) Netflix synopses are concise (~25 words), constraining lexical separation for subtle genres. (3) Natural user rating skew required class-balanced loss weighting during classification.

Future Scope: (1) Transition from cosine similarity to Matrix Factorization (SVD) and Neural Collaborative Filtering (NCF). (2) Ingest streaming clickstream telemetry (completion rate, pause points) via Kafka. (3) Containerized Kubernetes microservices deployment with continuous retraining.

13. Conclusion

This mini-project successfully engineered an integrated Data Mining and Analytics architecture fulfilling all course outcomes (CO1–CO5). An automated ETL pipeline structured 100,836 ratings and 8,807 streaming titles into an analytical SQLite Fact Constellation warehouse. Association mining mined 935 high-lift co-viewing rules, text mining classified plot synopses, Random Forest predicted rating tiers with 63.01% accuracy, Lasso regression isolated critical genre features, and ARIMA(3,1,3) forecasted monthly platform additions with a 22.47% error reduction over baseline persistence. The hybrid recommender and responsive Flask dashboard demonstrate how multidimensional warehousing and core data mining algorithms unite into a practical production system.
